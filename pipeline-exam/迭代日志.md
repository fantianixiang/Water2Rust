# 外部（CPU 流水线）优化迭代日志（Water2GPU · hydro 主机侧）

> 本文档记录 Water2GPU 中**非 GPU** 部分——即 hydro 整条 CPU 流水线（`water2rust hydro`：
> IO / warp / 栅格化 / 瓦片 / 逐河流多边形几何+求解 / 裙边等）**每一次优化迭代的决策与结论**。
> GPU 计算核（Laplace 求解器）的迭代记录在 [cuda-exam/迭代日志.md](../cuda-exam/迭代日志.md)，与本文分离。
>
> **方法**：先插桩测量（env `WATER_HYDRO_PROFILE=1`）再动手，拒绝凭假设优化；每步 **md5 逐位校验**输出不变。

---

## H1 —— 全流水线 profile：证伪「IO/栅格化/瓦片占大头」

- **背景**：全量林芝 hydro **47s**（输出 18138×26492 ≈4.8 亿像素）。直觉以为 IO / 栅格化 / 瓦片是大头。
- **做法**：给瓦片路径（`pipeline.rs`）+ `compute_water_surface` + `solve_river_polygon_surface` 三层加 env-gated 分步计时。
- **结果（纠正假设）**：全 47s 中——全幅铺底读 4.75–9.4s（IO，OS 缓存波动）、瓦片墙钟 32.9s、输出写盘 1.3s。
  瓦片内（跨 4 线程累加）：读 6.9s、warp 15.7s、**解算 75.9s**、组合 1.6s。解算再拆：**逐河流多边形 river_solve 50.3s**
  （66%，集中在 414k 主河瓦片 24.5s）、**抬升+裙边 24.7s**（均匀 ~4s/瓦片，与水量无关）、**栅格化仅 0.25s（可忽略！）**。
- **结论**：**栅格化根本不是瓶颈**。真瓶颈是 river_solve（逐多边形河流几何+求解）与 skirt/floor（全网格逐像素），
  其次 warp、IO。且 CLI 未接 GPU、Laplace 走 CPU faer（但线性解本身仅 ~0.5s，非瓶颈）。

## H2 —— 定位到 `spatial_p30_clamp`：全网格秩滤波只用稀疏站点

- **背景**：H1 发现 river_solve 是大头。再给其 11 个子阶段插桩（阈值 >1s 才打印）。
- **结果**：414k 主河多边形（12055 站点）21.76s 中——**`spatial_p30_clamp` = 17.63s（81%！）**，gauss_clamp 2.36s，
  medial/edt ~1s，**Laplace 线性解仅 0.50s**。
- **根因**：`spatial_p30_clamp` 对 z_smooth 做「空间 P30 下压」，其 `percentile_filter_2d` 在**整个 lh×lw 网格
  （15.5M 像素）**跑 O(h·w·size²) 的秩滤波，**但结果只在 ~12k 个骨架站点像素被读取**——其余 99.9% 像素纯属无用功
  （与 GPU 侧「紧凑变量免空 bbox」如出一辙）。
- **修复**：water-core 新增 `percentile_filter_2d_at(data, pct, size, points)`——只在给定查询点算秩滤波，与全网格版
  **逐位一致**（同 reflect 边界 / 窗口填充顺序 / NI_Select）；`spatial_p30_clamp` 改为只在站点算。
- **结果**：主河 p30 **17.63s → 0.06s（294×）**，river_solve 21.76→4.37s。**全 hydro 47s → 33s**（1.43×），
  输出 **md5 逐位一致**（golden 校验通过）+ river 核对拍 + 新原语单测通过。
- 附带 H2b：`solve_laplace_per_polygon` 逐多边形循环并行化（rayon + 串行序缝合 = 逐位一致）——但大河是单巨多边形
  主导，收益小（~2.5s）；仍保留（多多边形瓦片受益）。
- **结论**：又一次「全域算、稀疏用」的浪费——只在真正需要的点计算即得两个数量级提速，且零精度损失。剩余热点：
  gauss_clamp（~9s，全网格高斯只用站点，但可分离难限点、有 parity 风险，暂缓）、warp/IO（eci-gdal 子模块）、
  skirt EDT+膨胀（~4s/瓦片，全网格，可 bbox/并行，待办）。

> 工具：`WATER_HYDRO_PROFILE=1` 打印 pipeline / compute_water_surface / river_solve 三层分步耗时。
